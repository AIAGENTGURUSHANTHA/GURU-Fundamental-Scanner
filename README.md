# GURU Fundamental Scanner

A comprehensive stock and ETF analysis platform for Indian markets.

**Features:**
- Fundamental stock screening
- Technical analysis (DMA, EMA, RSI, SMC)
- Base Price Screener (3yr / 5yr SMA)
- GURU SMART BUSINESS screener
- Turtle Trading screener
- My Holdings portfolio tracker with live NSE prices
- Persistent data storage via Neon PostgreSQL
